# UART_Controller
UART Controller RTL-to-GDSII implementation using open-source EDA tools and the Sky130A PDK.
This project demonstrates the complete ASIC implementation flow of a UART (Universal Asynchronous Receiver/Transmitter) Controller, starting from Verilog RTL design and functional simulation and progressing through logic synthesis, static timing analysis, floorplanning, placement, clock tree synthesis, routing, physical verification, DRC, and LVS.

The design is implemented using the open-source SkyWater Sky130A PDK and open-source EDA tools, providing practical exposure to the complete RTL-to-GDSII physical design flow.

Key stages: RTL Design → Simulation → Synthesis → STA → Floor-planning → Placement → CTS → Routing → DRC → LVS → GDSII
